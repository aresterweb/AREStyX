RULES

Aturan Priority Request

Review dulu. Permintaan yang tidak realistis, melanggar hukum/kebijakan, atau membutuhkan akses data sensitif dapat ditolak.

Tidak eksklusif. Kecuali ada kesepakatan custom terpisah, tool yang dibuat menjadi bagian AREStyx dan dapat digunakan publik.

Scope terkunci. Perubahan besar setelah pekerjaan dimulai dapat dinilai sebagai request baru atau upgrade tier.

Keamanan. Jangan kirim kredensial, API key, kartu, rekening, atau dokumen identitas pada form/issue publik.
